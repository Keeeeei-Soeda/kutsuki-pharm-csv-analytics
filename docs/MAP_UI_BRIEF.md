# 指示書：商圏マップ（map.html）の UI 修正

- 対象: `src/build_map.py`（`docs/map.html` は生成物。直接編集しない）、`templates/_sidebar.css`、`docs/js/filters-ui.js`、`docs/js/pages/map.js`
- 確認した画面: `map.html?from=2024-09&to=2026-07&clinic=C001`、表示幅 754px（サイドバーがドロワーになる幅）
- 公開中の地図はまだ地理院タイル＋Leaflet のまま（Google マップ版は反映されていない）。以下の修正は **Google マップ版にしても同じ問題が起きないよう、両方の描き方で対応**すること
- この指示書は作業の正本とする

---

## 優先度 高（表示が壊れている）

### 1. 地図がヘッダーとドロワーの上に重なる
- 修正: 地図の枠（`#map` の親 `.map-shell`）に `position: relative; z-index: 0; isolation: isolate;` を付け、地図内の重なり順を枠の中に閉じ込める。ヘッダー・ドロワー・背景の `z-index` は変えない

### 2. 凡例の色が地図と合っていない
- 修正: 凡例の円は色を持たないグレーの輪郭（大きさだけを示す）にし、その下に「● 門前以外（青）」「● 門前（オレンジ）」の色の見本を別行で出す

### 3. クリニックのフィルタが地図に効いていない
- 指定クリニックを強調、他は透明度 .15。自店＋選択院に fit。`dept` で診療科絞り込み
- 案内文: 「クリニック・診療科の指定は地図に反映されます。円の大きさは全期間の処方箋枚数です。」

### 4. 自店の印が見えない
- 自店専用ペイン（最前面）。白縁つき濃い緑の二重丸／ピン
