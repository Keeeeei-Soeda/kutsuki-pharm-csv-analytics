## 0. 要約

1. **数字の食い違いを先に直す。** 「門前＝40m以内」に変えた影響が、Phase 3・4・5・6 の図と文言に残っており、素人が最初に信用を失う箇所になっている（第2章）。
2. **軸を「門前／門前以外」から「隣の2院／それ以外」に変える。** 門前が1%になった今、門前軸は素人に意味を持たない。店の実態は「はせがわ・平山の2院で大半、残りが面」である（第3章）。
3. **「次にやること」を、指名（誰・どこ・何枚・いつ）と測り方まで書く。**
4. **トップに「今月のやることリスト」を置き、各ページから自動で集める。**
5. 新しく足すものは、2院依存の「枚数シナリオ」、地図の結論ボックス、年齢構成の1項目、施策の記録欄、来なくなった常連のリストの5つ（第5章）。
