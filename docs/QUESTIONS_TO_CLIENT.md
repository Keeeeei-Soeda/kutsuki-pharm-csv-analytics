# 依頼者への確認事項（QUESTIONS_TO_CLIENT）

## Phase 0 で確定させたいこと

1. **対象店舗**は「くつき薬局沢良宜店」か「**南茨木店**」か。データバンク固定点は南茨木店。
2. 目標の「月1,800枚」の定義は？ 実測の月平均受診明細は約 **1388件**（23か月）。処方箋枚数 / 受付回数 / 明細件数のどれか。
3. 開局日・移転日・現住所での営業開始日は？
4. 大淀店・沢良宜店も同一スキーマで入手可能か（外部妥当性・DiD）。

## 優先度A（理論完成に必須）

1. クリニック別の総処方箋発行数（自店シェア分母）
2. 競合薬局の規模代理指標（薬剤師数、店舗面積、口コミ件数等）
3. 他店舗（大淀・沢良宜）の同一スキーマデータ
4. イベント年表（開局・移転・営業時間変更・近隣クリニック開閉院・競合開閉局・広告）→ 施策分は受領済（下記 Phase 5 参照）

## 優先度B

5. 受診ごとの診療科・薬効分類・処方日数・点数
6. 患者の性別
7. 待ち時間実測と時間帯別来局数
8. Googleビジネスプロフィール指標の時系列
9. 祝日カレンダー（またはフラグ付与の承認）
10. **生年月日**の提供可否（現状 patient_master で全空欄。受診時点年齢の再計算に必要）

## 優先度C（Experience Engine）

11. 患者アンケート（安心・信頼・満足・NPS・認知）300〜400件、患者ID紐付け可能な同意設計
12. 初回来局のきっかけ（門前/以前から/紹介/検索/看板）

## Phase 5（施策年表 2026-09-30受領）で前提にした点

以下を仮定して推定した。違っていれば `config/events.yaml` を直して再実行する。

1. Excel の列は **2024年9月〜2026年8月** でよいか。
2. 「↑」の位置と注記内の日付がずれる箇所は、**注記内の日付**が正しいか。
3. ポスティングの**配布エリア**（地図または町丁目リスト）。現状は薬局から1.0km以内と仮定。
4. MEOコンサルの**開始日**（現状は 2025-04-01 と仮定）。
5. 補助資料の **2026-08** は途中集計か（受付回数2292に対し処方箋枚数1294）。
6. 「オンライン/全体」行が `#REF!` になっている。元の値があれば欲しい。
