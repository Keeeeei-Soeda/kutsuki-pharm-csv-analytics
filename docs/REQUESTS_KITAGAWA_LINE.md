## A. データ補正

### A-0. 着手前の確認事項（回答待ち）

1. **はせがわ・平山の補正値「0.3」と門前フラグ「40m以内」が両立しない。**
   0.3km＝300m にすると、40m 基準では2院とも門前から外れる。
   原文の意図（「門前で実際距離が近いので補正いる」）からは **0.03km（30m）** の可能性が高い。
   0.3km と 0.03km のどちらか。
2. **2026-09-17 の既存指示との食い違い。** `config/corrections.yaml` に
   「はせがわ（C001）の道路km を 0.04 にする」（未適用）がある。今回の値で置き換えてよいか。
3. **門前フラグ「40m」は直線距離か道路距離か。** 現状の門前判定は直線 300m 以内相当。
4. **40m 基準で新たに門前になる／外れるクリニック**（下表）を意図どおりとしてよいか。
   特に C009 髙岡クリニック（直線 37m）は補正対象外のまま門前に残り、
   C003 藤井クリニック（直線 44m）は門前から外れる。
5. **立地パターン（門前型／患者近接型／経由型／遠隔型）の再判定ルール。**
   門前型から外れたクリニックの受診を、残り3型のどれに振るかの基準が生データにない。

### A-1. 距離の補正

対象列は `クリニック→薬局_直線km` と `クリニック→薬局_道路km` の2列。

| ID | クリニック | 現在の直線km | 現在の道路km | 補正後（指示） |
|---|---|---|---|---|
| C001 | 医療法人はせがわ耳鼻咽喉科 | 0.030 | 0.146 | 0.3（A-0 の1で確認） |
| C002 | 平山皮フ科クリニック | 0.037 | 0.044 | 0.3（同上） |
| C018 | 高原クリニック | 0.030 | 0.146 | 0.6 |
| C019 | 医療法人 歯徳会 芝歯科クリニック | 0.034 | 0.032 | 0.6 |

- C018 は C001 と座標・距離が完全に一致しており、住所の変換で同じ建物に寄せられたと見られる。「門前とは言えない距離」という指摘と整合する。
- 実装は既存の補正の仕組み（`config/corrections.yaml` → `src.corrections`）に登録する。`data/raw/` は書き換えない。
- 波及先: 指示は `visit_history` と `visit_history_with_weather_pollen` だが、同じ2列は以下にもある。1ファイルだけ直すと分析間で数値が食い違うため、全ファイルに波及させる。
  - `clinic_master`
  - `clinic_master_from_prescriptions`
  - `visit_history`
  - `visit_history_with_weather_pollen`
  - `visit_triangle`
  - `patient_clinic_with_distance`
- 名前の突合（`expect_name`）を各補正に書き、`python3 -m src.corrections --verify` で確認してから有効にする。

### A-2. 門前フラグを 40m 以内に再定義

現在の門前フラグは `visit_triangle` の既存列で、直線 0.3km 以内のクリニックが TRUE になっている（18院）。

| 定義 | 門前になるクリニック | 門前の受診件数シェア |
|---|---|---|
| 現状（直線 約300m 以内） | 18院 | 90.4%（立地パターン門前型は 89.3%） |
| 40m・補正なし | C001, C002, C009, C018, C019 | 約74% |
| 40m・補正あり（C001/C002=0.03 と解釈） | C001, C002, C009 | 約73% |
| 40m・補正あり（C001/C002=0.3 の文字どおり） | C009 のみ | 約1% |

- 門前比率は Phase 1〜6 すべての層別の土台なので、変更後は **全 Phase の再実行**が必要。
- 変更前の結果との比較表（門前比率、主要 KPI の前後）を `reports/correction_impact.md` に出す。
- 感度分析として、旧定義（300m）の結果もレポートに併記する。

## B. 分析の追加

A の補正後のデータで実施する。

### B-1. はせがわ・平山を除いた抽出と統計分析

- C001・C002 経由の受診を除いたデータで、Phase 1〜4 の主要指標を再計算する。
- 狙い: 門前2院の患者数に埋もれている「面」の患者像を見る（2院で受診の約72%）。
- 出力: 全体版と除外版の並列比較（件数、商圏、定着、年齢構成）。

### B-2. 年齢に関する統計の追加

- 仮説（北川氏の戦略）: 開局〜2年は子育て中の30代、それ以降は60代以上の慢性疾患患者。
- 分析:
  - 初回来局月ごとの年齢階級構成の推移
  - 年齢階級別の定着率と来局頻度
  - 年齢階級×門前／非門前
- 制約:
  - 年齢は基準日 2026-07-31 時点の固定値で、生年月日は全件空欄。受診時点の年齢は±2歳の誤差を含む（`docs/DATA_ISSUES.md`）。
  - 性別と世帯（子の有無）はデータにない。「子持ち主婦」は、0〜9歳の受診と30代の受診が同じ住所座標で同時期にある、という代理指標でしか近似できない。

### B-3. 定着の定義の再設定（90日 と 180日）

- 現状は「初回から90日以内の再来」（Phase 4）。
- 90日と180日の両方で定着率を出し、層別の順位や係数の向きが変わるかを比較する。
- 観察窓が満了していない直近の初回患者は除外する（180日版は除外が増える）。
- 処方日数のデータがないため、慢性疾患（長期処方）の患者は90日では過小評価になりうる点をレポートに書く。

### B-4. リピート率の算出

- 定義案: 初回後に2回目の来局がある患者の割合。観察期間をそろえるため、初回から N 日以内で区切る。
- 月次推移と、門前／非門前・年齢階級・距離帯別に出す。

### B-5. 離脱患者の具体化

- 定義案: 最終来局から、本人の来局間隔の中央値の3倍または180日を過ぎても来ていない患者。
- 離脱者と継続者のプロフィール（年齢、距離、初回クリニック、初回診療科、来局回数）を比較する。
- 「不足薬による離脱」（C-4）はデータがないため、ここでは扱えない。

### B-6. 患者—クリニック—薬局の距離と角度の傾向

- 座標から、患者の自宅を頂点にしたクリニック方向と薬局方向の角度を計算する。0度＝同じ方向＝通り道。
- 角度の分布、および角度と来局率・定着・非門前比率の関係を見る。
- 既存の迂回率（`visit_triangle`）と合わせて「通り道にある薬局が選ばれているか」を検証する。
