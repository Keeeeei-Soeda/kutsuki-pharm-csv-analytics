## 3. 見てもらいたい論点（現時点で判断がついていないもの）

### 論点1: 集計来局率モデルの評価

- モデル: Binomial GLM（`var_weights=人口`）、目的変数 = 自店ユニーク来局 ÷ 住基人口
- サンプル: 地域×年齢×年、道路距離 ≤30km、N行=2,808 / 地域数=52
- 年齢固定効果・年固定効果、標準誤差は HC1
- 主要係数: `log(道路距離)` の **OR=0.096**、AIC=116,667
- 別仕様（メッシュ単位）: `log(距離)` の **OR=0.316**、最近隣競合km の OR=0.579

**聞きたいこと**

1. 適合度をどう報告すべきか。**現状このモデルには疑似R²を出していない**
   （Binomial GLM のため R² は一意に定まらない）。McFadden・Nagelkerke・deviance比の
   どれを、どう注釈して出すのが妥当か。
2. 「対象地域」を道路距離30km・52地域と切ったことは妥当か。
   実質的な商圏（中央値〜1km）に対して裾が長すぎないか。切り方で係数がどれだけ動くかを
   どう示すべきか。
3. `var_weights=人口` と HC1 の組み合わせで、地域内クラスタ相関を十分に扱えているか。
   地域クラスタロバスト標準誤差にすべきか。

> **注記（社内確認事項）**: レビュー時に「集計来局率GLMの R²≒0.316」という言及があったが、
> 0.316 は**メッシュ版モデルの log距離のオッズ比**であり、決定係数ではない。
> 依頼前にこの取り違えを解消しておくこと。

### 論点2: 条件付きロジットの門前ダミーが同義反復になっていないか

- モデル: 条件付きロジット（患者のクリニック選択）、N患者=692、選択肢は半径5km・平均約177.8施設
- 係数: `β門前 = 5.240`（SE 0.219）、`β距離 = -0.492`（SE 0.156）、`β log標榜数 = -3.077`
- McFadden R² = 0.584

**聞きたいこと**

1. 「門前」は薬局から0.3km以内という**立地の定義**であり、
   観測されるのは**その薬局に来た患者**だけである。
   β=5.24 は「門前クリニックの患者は門前薬局を選ぶ」という定義上ほぼ自明な関係を
   測っているだけではないか（同義反復の懸念）。
2. もしそうなら、この係数から意味のある含意を引き出すことは可能か。
   それとも「門前は統制変数として入れ、解釈は距離と標榜数に限る」べきか。
3. 選択集合を「半径5km内の全クリニック」としているが、患者が実際に検討した集合とは
   一致しない。この定式化で IIA はどこまで問題になるか。

### 論点3: 自店患者のみのデータから言えること／言えないことの境界

- 全ての指標の分母が「自店に来た患者」である。
- 例: メッシュ来局率 = 自店ユニーク来局 ÷ メッシュ人口。分子に他薬局利用者は入らない。
- 例: 来院経路分析の「診療科を変えた」は、「他薬局で調剤した」と区別できない。

**聞きたいこと**

1. この構造で「市場シェア」「選択率」という語を使うことは避けているが、
   他に注意すべき言い換えの落とし穴はあるか。
2. 選択バイアスの大きさを、追加データなしで見積もる方法はあるか
   （感度分析・バウンド分析など）。
3. 経営者向けに「これは記述であって因果ではない」をどう伝えるのが実務的か。

### 論点4: 1店舗の観測で外部妥当性をどこまで主張できるか

- 観測単位は1店舗・23か月。クリニックは434施設あるが、すべて同一薬局経由。
- Phase 6 の月次予測では移動平均3が最良（MAE≈126, MAPE≈6.8%）で、
  構造モデルが単純なベースラインに勝てていない。

**聞きたいこと**

1. 「この薬局ではこうだった」以上のことを言えるか。言えるとすれば何が条件か。
2. 構造モデルが移動平均に負けている状態を、どう報告すべきか
   （モデルを捨てるべきか、説明用として残すべきか）。
3. 学会・論文化を考える場合、1店舗研究として成立させる最低条件は何か。
