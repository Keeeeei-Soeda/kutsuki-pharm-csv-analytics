凡例と縮尺の考え方

クリニック（円＝件数）

半径は log1p(件数) に比例。件数をそのまま半径にすると 最大施設1点だけが巨大になり、他が読めなくなるため。表示している数値は実数。

メッシュ来局率

500mメッシュの「自店来局ユニーク患者 ÷ メッシュ人口」。 最大 22.2%。色は非ゼロ値の五分位で割っている （対数でも右に寄って読めないため）。

読み方と限界

  • クリニックの円は自店を経由した処方箋件数であり、そのクリニックの総発行数ではない。 自店シェアの分母は観測できない。
  • メッシュ来局率の分子は自店患者のみ。他薬局の利用は含まないため、 地域の「薬局利用率」ではなく自店の浸透度として読む。
  • 患者密度は集約値。セル単位の件数は 3 件以上のものだけを使っている。
  • 競合薬局は所在のみ。処方箋枚数は未取得のため、圧力は立地・営業時間の代理指標。
  • タイルは国土地理院・OpenStreetMap。Google Maps JS API はキー発行と課金設定が必要なため、 要件になった段階で差し替える。
